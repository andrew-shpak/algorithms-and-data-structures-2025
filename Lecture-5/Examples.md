## 1. Вступ

**Сортування** — це впорядкування елементів послідовності за деяким критерієм (наприклад, за зростанням).

Навіщо сортувати:
- **Бінарний пошук** працює лише на відсортованих даних — O(log n) замість O(n)
- Легко знаходити **дублікати**, медіану, k-тий елемент
- Багато алгоритмів (жадібні, два вказівники) починаються зі сортування

Важливі характеристики алгоритму сортування:

| Характеристика | Що означає |
|----------------|-----------|
| Часова складність | Скільки порівнянь/обмінів у найкращому, середньому, найгіршому випадку |
| Додаткова пам'ять | Чи сортує «на місці» (in-place, O(1)) |
| Стабільність | Чи зберігає відносний порядок рівних елементів |

## 2. Прості сортування: O(n²)

### Бульбашкове сортування (Bubble Sort)

Проходимо масив і міняємо сусідні елементи, якщо вони стоять неправильно. Після кожного проходу найбільший елемент «спливає» в кінець.

```csharp
int[] a = [5, 1, 4, 2, 8];
BubbleSort(a);
Console.WriteLine(string.Join(' ', a));     // виводимо результат

// Бульбашкове сортування за зростанням (Span<int> — працює і з масивом, і з його частиною)
static void BubbleSort(Span<int> a)
{
    int n = a.Length;
    for (int i = 0; i < n - 1; i++)
    {
        bool swapped = false;               // чи був хоч один обмін за прохід
        // останні i елементів вже на своїх місцях
        for (int j = 0; j < n - 1 - i; j++)
        {
            if (a[j] > a[j + 1])            // сусіди стоять неправильно
            {
                (a[j], a[j + 1]) = (a[j + 1], a[j]); // обмін через кортеж
                swapped = true;
            }
        }
        if (!swapped) break;                // обмінів не було — масив відсортовано, O(n) у найкращому випадку
    }
}
```

**Приклад запуску:**
```
1 2 4 5 8
```

### Сортування вибором (Selection Sort)

На кожному кроці знаходимо мінімум у невідсортованій частині та ставимо його на початок.

```csharp
int[] a = [64, 25, 12, 22, 11];
SelectionSort(a);
Console.WriteLine(string.Join(' ', a));

// Сортування вибором: завжди O(n²) порівнянь, але не більше n-1 обмінів
static void SelectionSort(Span<int> a)
{
    int n = a.Length;
    for (int i = 0; i < n - 1; i++)
    {
        int minIdx = i;                      // індекс мінімуму в a[i..n-1]
        for (int j = i + 1; j < n; j++)
        {
            if (a[j] < a[minIdx]) minIdx = j;
        }
        // обмін на відстань робить алгоритм НЕстабільним
        (a[i], a[minIdx]) = (a[minIdx], a[i]);
    }
}
```

**Приклад запуску:**
```
11 12 22 25 64
```

### Сортування вставками (Insertion Sort)

Як сортування карт у руці: беремо наступний елемент і вставляємо його на правильне місце серед уже відсортованих.

```csharp
int[] a = [12, 11, 13, 5, 6];
InsertionSort<int>(a);
Console.WriteLine(string.Join(' ', a));

// Узагальнене сортування вставками: O(n) на майже відсортованих даних, стабільне
static void InsertionSort<T>(Span<T> a) where T : IComparable<T>
{
    for (int i = 1; i < a.Length; i++)
    {
        T key = a[i];                        // елемент, який вставляємо
        int j = i;
        // зсуваємо вправо всі елементи, строго більші за key
        // (строга нерівність > 0 зберігає стабільність)
        while (j > 0 && a[j - 1].CompareTo(key) > 0)
        {
            a[j] = a[j - 1];
            j--;
        }
        a[j] = key;                          // ставимо key у звільнену позицію
    }
}
```

**Приклад запуску:**
```
5 6 11 12 13
```

> На практиці insertion sort використовують для **малих** масивів (у .NET — до 16 елементів) — саме так робить гібридна реалізація `Array.Sort`.

## 3. Сортування злиттям (Merge Sort)

Принцип **«розділяй і володарюй»**:
1. Ділимо масив навпіл
2. Рекурсивно сортуємо кожну половину
3. **Зливаємо** дві відсортовані половини за O(n)

```
[38 27 43 3]  ->  [38 27] [43 3]  ->  [27 38] [3 43]  ->  [3 27 38 43]
```

Рекурентність T(n) = 2T(n/2) + O(n) дає **O(n log n)** завжди, але потрібна додаткова пам'ять O(n).

```csharp
int[] a = [38, 27, 43, 3, 9, 82, 10];
int[] tmp = new int[a.Length];               // один буфер на все сортування
MergeSort(a, 0, a.Length - 1, tmp);
Console.WriteLine(string.Join(' ', a));

// Злиття двох відсортованих частин a[l..m] та a[m+1..r]
static void Merge(int[] a, int l, int m, int r, int[] tmp)
{
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r)
    {
        // "<=" бере елемент з лівої частини при рівності — це робить сортування стабільним
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else              tmp[k++] = a[j++];
    }
    while (i <= m) tmp[k++] = a[i++];        // дописуємо залишок лівої частини
    while (j <= r) tmp[k++] = a[j++];        // дописуємо залишок правої частини
    Array.Copy(tmp, l, a, l, r - l + 1);     // копіюємо злитий діапазон назад
}

static void MergeSort(int[] a, int l, int r, int[] tmp)
{
    if (l >= r) return;                      // 0 або 1 елемент — вже відсортовано
    int m = l + (r - l) / 2;                 // так уникаємо переповнення (l + r)
    MergeSort(a, l, m, tmp);
    MergeSort(a, m + 1, r, tmp);
    Merge(a, l, m, r, tmp);
}
```

**Приклад запуску:**
```
3 9 10 27 38 43 82
```

## 4. Швидке сортування (Quick Sort)

1. Обираємо **опорний елемент** (pivot)
2. **Розбиваємо** масив: менші за pivot — ліворуч, більші — праворуч
3. Рекурсивно сортуємо обидві частини

- Середній випадок: **O(n log n)**, сортує на місці, дуже швидкий на практиці
- Найгірший випадок: **O(n²)** — коли pivot щоразу мінімальний/максимальний (напр., вже відсортований масив і pivot = останній елемент). Рятує **випадковий pivot**.

```csharp
var rng = new Random(42);                    // генератор випадкових чисел (фіксоване зерно для відтворюваності)

int[] a = [10, 7, 8, 9, 1, 5];
QuickSort(a, 0, a.Length - 1, rng);
Console.WriteLine(string.Join(' ', a));

// Розбиття Ломуто: повертає фінальну позицію pivot
static int Partition(int[] a, int l, int r, Random rng)
{
    // обираємо випадковий pivot з [l, r] і переносимо його в кінець
    int p = rng.Next(l, r + 1);              // верхня межа Next — виключна
    (a[p], a[r]) = (a[r], a[p]);
    int pivot = a[r];
    int i = l;                               // межа: a[l..i-1] < pivot
    for (int j = l; j < r; j++)
    {
        if (a[j] < pivot)
        {
            (a[i], a[j]) = (a[j], a[i]);
            i++;
        }
    }
    (a[i], a[r]) = (a[r], a[i]);             // ставимо pivot на своє місце
    return i;
}

static void QuickSort(int[] a, int l, int r, Random rng)
{
    if (l >= r) return;
    int p = Partition(a, l, r, rng);
    QuickSort(a, l, p - 1, rng);             // ліва частина (менші)
    QuickSort(a, p + 1, r, rng);             // права частина (більші або рівні)
}
```

**Приклад запуску:**
```
1 5 7 8 9 10
```

## 5. Array.Sort та компаратори

У реальному коді використовуємо стандартну бібліотеку .NET. `Array.Sort` та `List<T>.Sort` — це **introsort** (quick sort + heap sort + insertion sort): O(n log n) у найгіршому випадку, **нестабільні**.

**Компаратор** — `Comparison<T>` (лямбда `(a, b) => ...`) або `IComparer<T>` — повертає **від'ємне** число, якщо `a` має стояти **перед** `b`, **нуль** при рівності та **додатне** — інакше. Він має бути узгодженим: `cmp(a, a) == 0` і `cmp(a, b) == -cmp(b, a)`.

```csharp
int[] v = [5, 2, 9, 1, 7];

Array.Sort(v);                                        // за зростанням (IComparable<int>)
Console.WriteLine(string.Join(' ', v));

Array.Sort(v, (x, y) => y.CompareTo(x));              // за спаданням: міняємо аргументи місцями
Console.WriteLine(string.Join(' ', v));

List<Student> s = [new("Olena", 90), new("Ivan", 75), new("Andrii", 90), new("Maria", 82)];

// лямбда-компаратор: спершу за оцінкою (спадання), при рівності — за ім'ям (зростання)
s.Sort((a, b) =>
{
    if (a.Grade != b.Grade) return b.Grade.CompareTo(a.Grade);
    return string.CompareOrdinal(a.Name, b.Name);
});

foreach (var st in s) Console.WriteLine($"{st.Name} {st.Grade}");

// record — незмінний тип із автоматичними властивостями Name та Grade
record Student(string Name, int Grade);
```

**Приклад запуску:**
```
1 2 5 7 9
9 7 5 2 1
Andrii 90
Olena 90
Maria 82
Ivan 75
```

> Порада: для порівняння за кількома полями зручно використовувати кортежі: `(b.Grade, a.Name).CompareTo((a.Grade, b.Name))`, або LINQ: `s.OrderByDescending(x => x.Grade).ThenBy(x => x.Name)`.

## 6. Стабільність сортування

**Стабільне** сортування зберігає початковий порядок елементів з рівними ключами. Це важливо, коли сортуємо за кількома критеріями поетапно.

| Стабільні | Нестабільні |
|-----------|-------------|
| Bubble, Insertion, Merge, LINQ `OrderBy`/`ThenBy` | Selection, Quick, Heap, `Array.Sort`, `List<T>.Sort` |

```csharp
// замовлення вже впорядковані за часом надходження
Order[] orders = [new("A", 2), new("B", 1), new("C", 2), new("D", 1), new("E", 2)];

// LINQ OrderBy — стабільний: серед однакових Priority порядок A..E збережеться.
// Повертає НОВУ послідовність (O(n) пам'яті), вихідний масив не змінюється.
var sorted = orders.OrderBy(o => o.Priority);   // лише за пріоритетом

Console.WriteLine(string.Join(' ', sorted.Select(o => $"{o.Customer}:{o.Priority}")));

record Order(string Customer, int Priority);
```

**Приклад запуску:**
```
B:1 D:1 A:2 C:2 E:2
```

З `Array.Sort` результат міг би бути, наприклад, `D:1 B:1 E:2 A:2 C:2` — порядок надходження втрачено. Щоб отримати стабільність «на місці», можна додати початковий індекс як другий ключ порівняння.

## 7. Таблиця складності

| Алгоритм | Найкращий | Середній | Найгірший | Пам'ять | Стабільний |
|----------|-----------|----------|-----------|---------|-----------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | Так |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | Ні |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | Так |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Так |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | Ні |
| `Array.Sort` | O(n log n) | O(n log n) | O(n log n) | O(log n) | Ні |
| LINQ `OrderBy` | O(n log n) | O(n log n) | O(n log n) | O(n) | Так |

> Нижня межа для сортувань **порівнянням** — Ω(n log n). Швидше можна лише без порівнянь (counting sort, radix sort) за обмежень на ключі.

## 8. Підсумки

- Прості сортування (bubble, selection, insertion) — O(n²), корисні для навчання та малих масивів
- **Merge sort** — гарантовано O(n log n) і стабільний, але потребує O(n) пам'яті
- **Quick sort** — найшвидший на практиці, але O(n²) у найгіршому випадку; використовуйте випадковий pivot
- У реальному коді — `Array.Sort`/`List<T>.Sort` або LINQ `OrderBy`/`ThenBy`, якщо потрібна стабільність
- Компаратор має бути **узгодженим**: знак результату задає порядок, 0 — лише для рівних
