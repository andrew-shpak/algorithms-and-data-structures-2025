# Lab-8 - Дерева (Основи)

## Завдання 1: Структура вузла бінарного дерева та базові операції

### Мета
Навчитися створювати структуру бінарного дерева пошуку (BST), реалізувати базові операції вставки, пошуку та підрахунку вузлів.


- **Бали:** 1
- **Складність:** O(h) для insert та search, де h - висота дерева; O(n) для count_nodes, де n - кількість вузлів
### Приклад запуску

```
Кількість вузлів: 7
Пошук 40: Знайдено
Пошук 100: Не знайдено
```

---

## Завдання 2: Обходи дерева

### Мета
Реалізувати три основні рекурсивні обходи бінарного дерева: інфіксний (inorder), префіксний (preorder) та постфіксний (postorder).

- **Бали:** 1
- **Складність:** O(n) для кожного обходу, де n - кількість вузлів

### Приклад запуску

```
Інфіксний обхід (Inorder): 20 30 40 50 60 70 80
Префіксний обхід (Preorder): 50 30 20 40 70 60 80
Постфіксний обхід (Postorder): 20 40 30 60 80 70 50
```

---

## Завдання 3: Властивості та характеристики дерева

### Мета
Навчитися обчислювати різні властивості дерева: висоту, максимальне/мінімальне значення та кількість листків.


- Використовувати рекурсію для обчислення властивостей
- **Бали:** 1
- **Складність:** O(n) для всіх операцій, де n - кількість вузлів

### Приклад запуску

```
Висота дерева: 2
Максимальне значення: 80
Мінімальне значення: 20
Кількість листків: 4
```

## Завдання 4: Обхід дерева в ширину з використанням черги

### Мета
Реалізувати обхід дерева в ширину (Level Order Traversal / BFS) з використанням черги `std::queue`, навчитися працювати з нерекурсивним обходом.


- **Бали:** 1
- **Складність:** O(n), де n - кількість вузлів

### Приклад запуску

```
Обхід в ширину (по рівнях):
Рівень 0: 50
Рівень 1: 30 70
Рівень 2: 20 40 60 80

Кількість вузлів на кожному рівні:
Рівень 0: 1 вузлів
Рівень 1: 2 вузлів
Рівень 2: 4 вузлів
```
