# Завдання для movies.csv

- Прочитати CSV файл та відобразити записи фільмів (4 бали)
	- Створіть клас/структуру Movie, що відповідає структурі CSV файлу. (0.5 бала)
	- Структура має містити: назва, режисер, рік, вектор рейтингів, жанр, тривалість, бюджет, касові збори. (0.5 бала)
- Обчислити та відобразити середній рейтинг для кожного фільму (1 бал)
``` cpp
	Inception (Крістофер Нолан). Середній рейтинг: 8.7
	The Matrix (Вачовські). Середній рейтинг: 8.5
```
- Знайти та відобразити топ-3 фільми з найвищим та найнижчим середнім рейтингом (1 бал)
	- Використайте `std::sort` або `std::partial_sort` для сортування фільмів за рейтингом.
	- `std::partial_sort` є більш ефективним для пошуку топ-N елементів (O(N log K) замість O(N log N)).
``` cpp
	Топ-3 фільми з найвищим рейтингом:
	1. The Shawshank Redemption - 9.3
	2. The Godfather - 9.2
	3. The Dark Knight - 9.0

	Топ-3 фільми з найнижчим рейтингом:
	1. Disaster Movie - 1.9
	2. Epic Movie - 2.4
	3. Meet the Spartans - 2.8
```
- Відсортувати фільми за кількома полями (1 бал)
	- Використайте `std::tie` для порівняння кількох полів одночасно.
	- Спочатку за жанром, потім за рейтингом (спадання), потім за роком випуску.
``` cpp
	Топ-3 фільми за кожним жанром (відсортовані за рейтингом):

	Жанр: Бойовик
	1. The Dark Knight (2008) - 9.0
	2. Seven Samurai (1954) - 8.6
	3. Gladiator (2000) - 8.5

	Жанр: Драма
	1. The Shawshank Redemption (1994) - 9.3
	2. Schindler's List (1993) - 8.9
	3. Fight Club (1999) - 8.8
```

# Завдання для products.csv

- Прочитати CSV файл та відобразити записи товарів (4 бали)
	- Створіть клас/структуру Product, що відповідає структурі CSV файлу.(0.5 бала)
	- Структура має містити: назва, категорія, ціна, кількість, вектор рейтингів, постачальник, дата, знижка.(0.5 бала)
- Обчислити та відобразити середній рейтинг для кожного товару (1 бал)
``` cpp
	iPhone 14 Pro (Apple Inc.). Середній рейтинг: 4.8
	Samsung Galaxy S23 (Samsung Electronics). Середній рейтинг: 4.7
```
- Знайти та відобразити топ-5 товарів з найвищим та найнижчим середнім рейтингом (1 бал)
	- Використайте `std::sort` або `std::partial_sort` для сортування товарів за рейтингом.
``` cpp
	Топ-5 товарів з найвищим рейтингом:
	1. Chanel No.5 - 4.9
	2. MacBook Air M2 - 4.9
	3. PlayStation 5 - 4.9
	4. iPhone 14 Pro - 4.8
	5. Sony WH-1000XM5 - 4.8

	Топ-5 товарів з найнижчим рейтингом:

	2. Плаття H&M - 4.2
	3. Чай Lipton - 4.3
	4. Полиця книжкова - 4.3
	5. Дезодорант Rexona - 4.3
```
- Знайти та відобразити товари з найбільшою знижкою (топ-3) (1 бал)
``` cpp
	Товари з найбільшою знижкою:
	1. Плаття H&M - 35%
	2. Светр Zara - 30%
	3. Шафа-купе - 25%
```
- Обчислити та відобразити середню вартість товарів по категоріях (1 бал)
``` cpp
	Категорія: Електроніка. Середня ціна: 18456.78 грн
	Категорія: Одяг. Середня ціна: 3249.50 грн
	Категорія: Продукти. Середня ціна: 243.20 грн
	Категорія: Меблі. Середня ціна: 10299.10 грн
```
- Відсортувати товари за кількома полями (1 бал)
	- Використайте `std::tie` для порівняння кількох полів одночасно.
	- Спочатку за категорією, потім за знижкою (спадання), потім за рейтингом (спадання).
