## Завдання: Пошук найкоротших шляхів (Алгоритм Дейкстри)

### Мета
Реалізувати алгоритм Дейкстри для знаходження найкоротших шляхів від початкової вершини до всіх інших вершин у зваженому графі з невід'ємними вагами ребер. Навчитись працювати з пріоритетною чергою та ефективно обробляти зважені графи.

### Вимоги

Створіть програму, яка:

1. **Представлення графа (1 бал)**
   - Використовує список суміжності для зберігання зваженого графа
   - Кожне ребро містить інформацію про вершину призначення та вагу
   - Підтримує як орієнтовані, так і неорієнтовані графи

2. **Реалізація алгоритму Дейкстри (5 балів)**
   - Реалізує метод `Dijkstra(graph, start)`, яка повертає найкоротші відстані від початкової вершини до всіх інших
   - Використовує пріоритетну чергу (`PriorityQueue<TElement, TPriority>`) для ефективного вибору вершини з мінімальною відстанню
   - Правильно ініціалізує відстані (0 для початкової вершини, нескінченність для інших)
   - Оновлює відстані до сусідніх вершин за принципом релаксації ребер
   - Коректно обробляє випадки, коли деякі вершини недосяжні

3. **Відновлення шляху (2 бали)**
   - Реалізує метод для відновлення та виведення найкоротшого шляху від початкової вершини до заданої
   - Зберігає попередні вершини для кожної вершини в найкоротшому шляху
   - Виводить шлях у зрозумілому форматі (наприклад, "0 -> 2 -> 3 -> 4")

4. **Виведення результатів (1 бал)**
   - Виводить таблицю з відстанями від початкової вершини до всіх інших вершин
   - Для кожної вершини виводить найкоротший шлях до неї
   - Позначає недосяжні вершини як "INF" або "Недосяжна"

5. **Обробка кількох тестових випадків (1 бал)**
   - Програма працює з різними графами
   - Коректно обробляє граничні випадки:
     - Граф з однією вершиною
     - Відключені компоненти графа
     - Граф з циклами

**Всього балів:** 10

**Складність:** O((V + E) log V), де V - кількість вершин, E - кількість ребер
