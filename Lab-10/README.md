## Завдання 1: Пошук в ширину (BFS)

### Мета
Реалізувати алгоритм пошуку в ширину (Breadth-First Search) для обходу графа. Навчитись працювати з графами, представленими списком суміжності, та використовувати чергу (`Queue<T>`) для обходу.

### Вимоги

Створіть програму, яка:
- Приймає граф, представлений списком суміжності
- Реалізує метод `Bfs` для обходу графа в ширину від заданої вершини
- Виводить порядок відвідування вершин

**Бали:** 2

**Складність:** O(V + E), де V - кількість вершин, E - кількість ребер

### Приклад `Main`

```csharp
public static class Program
{
    // Метод для BFS обходу графа
    public static void Bfs(int start, List<List<int>> graph)
    {
        // Ваш код тут
    }

    public static void Main()
    {
        // Приклад графа (список суміжності)
        // Граф:
        //     0 --- 1
        //     |     |
        //     2 --- 3 --- 4
        List<List<int>> graph =
        [
            [1, 2],    // вершина 0 з'єднана з 1 та 2
            [0, 3],    // вершина 1 з'єднана з 0 та 3
            [0, 3],    // вершина 2 з'єднана з 0 та 3
            [1, 2, 4], // вершина 3 з'єднана з 1, 2 та 4
            [3]        // вершина 4 з'єднана з 3
        ];

        Console.Write("BFS обхід від вершини 0: ");
        Bfs(0, graph);
        Console.WriteLine();

        Console.Write("BFS обхід від вершини 2: ");
        Bfs(2, graph);
        Console.WriteLine();
    }
}
```

### Приклад запуску

```text
BFS обхід від вершини 0: 0 1 2 3 4
BFS обхід від вершини 2: 2 0 3 1 4
```

## Завдання 2: Пошук в глибину (DFS)

### Мета
Реалізувати алгоритм пошуку в глибину (Depth-First Search) для обходу графа. Навчитись використовувати рекурсію або стек (`Stack<T>`) для обходу графа в глибину.

### Вимоги

Створіть програму, яка:
- Приймає граф, представлений списком суміжності
- Реалізує метод `Dfs` для обходу графа в глибину від заданої вершини
- Виводить порядок відвідування вершин
- Реалізує як рекурсивну версію

**Бали:** 2

**Складність:** O(V + E), де V - кількість вершин, E - кількість ребер

### Приклад `Main`

