# Лабораторна робота 2 — 1 випадкове завдання з 5, 30 хвилин, 5 балів

> **C# / .NET 10.** [Налаштування та запуск](../LABS.md).

На початку роботи викладач випадково визначає для кожного студента **одне
завдання з п'яти**. На виконання призначеного завдання відводиться **30 хвилин**.
Максимальна оцінка — **5 балів**. Усі завдання мають середню складність.

| № | Завдання | Обов'язкова колекція |
|---|---|---|
| 1 | Унікальні частоти символів | `HashSet<int>` |
| 2 | Множення великих чисел | `List<int>` |
| 3 | Найменше число після видалення цифр | `Stack<char>` |
| 4 | Каскадне видалення однакових символів | `Stack<(char Symbol, int Count)>` |
| 5 | Найкоротше перетворення числа | `Queue<T>` і `HashSet<int>` |

Використовуйте стандартні колекції .NET, зазначені у своєму завданні.
Скопіюйте відповідний шаблон **`Program.cs`** у консольний проєкт і замініть
`throw new NotImplementedException()` власною реалізацією.
Кожен шаблон компілюється окремо; до реалізації методу запуск зупиняється
на заглушці. Демонстраційні виклики вже підготовлено, а очікуваний вивід
наведено для завершеного алгоритму. Готових реалізацій у матеріалі немає.

Вхідні дані відповідають умовам завдання; перевірку некоректних аргументів
реалізовувати не потрібно. Передавання `null` не передбачене.

## Завдання 1. Унікальні частоти символів — `HashSet<int>`

Дано рядок із малих латинських літер `a–z`. Знайдіть **мінімальну кількість
видалень символів**, після яких усі символи, що залишилися, матимуть різні
частоти. Повертайте кількість видалень, а не змінений рядок.

- Символи з нульовою частотою не враховуються.
- Обов'язково використайте `HashSet<int>` для збереження зайнятих частот.
  Для підрахунку символів дозволено масив `int[26]`.
- Довжина рядка — від 0 до 100 000. Для порожнього рядка результат — `0`.
- **Складність:** O(n + 26) часу та O(26) додаткової пам'яті, де n — довжина рядка.

Наприклад, у `"aaabbbcc"` частоти дорівнюють `3, 3, 2`. Після двох видалень
можна отримати частоти `3, 2, 1`, тому відповідь — `2`.

## Завдання 2. Множення великих чисел — `List<int>`

Два невід'ємні цілі числа задано списками десяткових цифр **від старшої до
молодшої**. Поверніть їхній добуток як новий `List<int>` у тому самому порядку.

- Кожен вхідний список містить від 1 до 200 цифр зі значеннями `0–9`.
- Вхід може містити початкові нулі. Результат не повинен містити зайвих
  початкових нулів; число нуль представляється списком `[0]`.
- Не змінюйте вхідні списки. Цифри результату зберігайте в `List<int>`.
- Заборонено використовувати `BigInteger` або перетворювати ціле вхідне число
  на `int`, `long`, `decimal` чи інший числовий тип. Окремі цифри й проміжні
  значення можна обробляти як `int`.
- **Складність:** O(n · m) часу та O(n + m) пам'яті для результату, де n і m —
  кількості цифр вхідних чисел.

## Завдання 4. Каскадне видалення однакових символів — `Stack<(char, int)>`

Дано рядок і число `k`. Видаляйте групи з **k сусідніх однакових символів**.
Після видалення частини рядка з'єднуються, тому можуть утворитися нові групи,
які також потрібно видалити. Поверніть рядок, у якому таких груп більше немає.

- Рядок містить від 0 до 100 000 малих латинських літер `a–z`;
  `1 <= k <= 100000`.
- Використайте `Stack<(char Symbol, int Count)>`: елемент містить символ
  і кількість його сусідніх повторень.
- Якщо група довша за k, вилучайте по k символів. Наприклад,
  `"aaaaa"` при `k = 3` перетворюється на `"aa"`.

- **Складність:** O(n) часу та O(n) додаткової пам'яті. Повторне сканування

## Завдання 5. Найкоротше перетворення числа — `Queue<T>` і `HashSet<int>`

на число `target`. За одну операцію дозволено додати 1, відняти 1 або
помножити поточне число на 2.

- `start`, `target` та всі проміжні значення повинні належати діапазону

- Використайте `Queue<T>` для станів, які потрібно опрацювати,
